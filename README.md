    <h2>1. Общие положения</h2>
    <p>Приложение <strong>Randomizer: Weighted Assembly</strong>  (Сокращенно RanWA, далее — «Приложение») разработано студией <strong>Xalwach Dev</strong> и уважает вашу конфиденциальность. В этой политике объясняется, какие данные могут собираться при использовании Приложения.</p>
    <p>Используя Приложение, вы даёте своё согласие на сбор и использование данных, описанных в этом документе.</p>

    <h2>2. Какие данные собираются и зачем</h2>
    <p>Приложение использует <strong>VK Ad SDK</strong> для показа рекламы. Этот SDK может собирать следующие данные для корректной работы рекламных объявлений:</p>
    <ul>
        <li><strong>Идентификатор устройства</strong> (Android Advertising ID) — используется для показа релевантной рекламы, оценки эффективности рекламных кампаний, а также для предотвращения мошеннических действий (например, искусственных кликов и установок);</li>
        <li><strong>IP-адрес</strong> — для определения региона и показа релевантных объявлений;</li>
        <li><strong>Данные об устройстве</strong> (модель, операционная система, язык) — для оптимизации отображения рекламы;</li>
        <li><strong>Взаимодействие с рекламой</strong> (показы, клики) — для анализа эффективности.</li>
    </ul>
    <p>Личные данные (имя, фамилия, email, телефон) <strong>не собираются и не передаются</strong> третьим лицам.</p>

    <h2>3. Передача данных третьим лицам</h2>
